## BOOMBOX videosu nasıl istenir
1. Bu repoda yeni bir **issue** aç. Başlık: `BOOMBOX: <konu>`
   ör. `BOOMBOX: Asansörün halatı koparsa ne olur?`
2. Gövde isteğe bağlı:
   ```
   ses: Fenrir
   not: hız regülatörü ve fren takozları mutlaka anlatılsın; özgün metin yaz
   ```
3. ~30 sn içinde bilgisayar işi alır: `isleniyor` etiketi + "Sıraya alındı" yorumu, sonra proje adı yorumu.
4. Video bitince (~30–45 dk): **indirme linki** (bu reponun Releases'i) + Instagram açıklaması yorum olarak gelir, issue `bitti` etiketiyle kapanır.
   Hata olursa `hata` etiketi + son log satırları yorumlanır; yeniden denemek için yeni issue aç.
